# Welcome to the blogs app

This is a *modern blogging platform* built with Next.js, featuring user authentication, blog post managament, and an intuitive interface

## Features

- Add blogs
- Users
- Authentication
- Personal reading lists
- Liking blogs

## Getting started

To start exploring

1. [Create](/register) an account
2. [Login](/login) to access your dashboard
3. [Create a new blog post](/blogs/new)
4. view [all blogs](/blogs) and [all users](/users)
